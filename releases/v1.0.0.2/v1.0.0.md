# Val's DnD AIO Beyond Patch v1.0.0

First release. This is a small add-on for [**DnD 5.5e All-in-One BEYOND**](https://github.com/Yoonmoonsik/bg3dnd) by Yoonmoonsik. It adds two per-character toggles that turn off some of the mod's rules. Both toggles start **off**, so installing the patch changes nothing until you turn one on.

## ✨ Features

Every party member gets two toggles on the passive bar. Each can be turned on or off per character at any time, and the change takes effect immediately.

### Spell Freedom
- Removes the **One Spell with a Spell Slot per Turn** rule, so you can cast more than one leveled spell per turn again (for example, one with your action and one with your bonus action).
- While it's on, the rule's passive is removed from the character sheet. Turn it off and the passive comes back.
- **Swift Witchcraft rework:** the feat only existed to get around that rule. With Spell Freedom on, it still gives +1 INT/WIS/CHA, and its action becomes a **free Quickened Spell once per Short Rest**: the next spell you cast that turn that costs an action costs a bonus action instead.

### Vanilla Short Rests
- Short rests heal like the base game again (half your max HP, or full HP with Durable or the "short rest heals to full" custom setting), instead of healing 1 HP and unlocking "Use Hit Point Dice".
- Hit Point Dice are still there for the features that spend them (Durable, Lifedrinker, Sangromancy, Dwarven Fortitude, etc.).

## 📦 Requirements
- [**BG3 Script Extender**](https://github.com/Norbyte/bg3se)
- [**DnD 5.5e All-in-One BEYOND**](https://github.com/Yoonmoonsik/bg3dnd), the original, unmodified

## 🔧 Installation
1. Install BG3 Script Extender and DnD 5.5e All-in-One BEYOND.
2. Download `ValBeyondPatch_decf7761-c0ea-30aa-4845-d9b0a6968ad8.pak` below and add it to your mods.
3. Load the patch **after** DnD 5.5e All-in-One BEYOND. BG3 Mod Manager sorts this automatically.
4. In game, turn on the toggles you want on each character's passive bar.

## 💾 Save Compatibility
- Safe to add to an existing campaign. With both toggles off, nothing changes.
- Safe to remove. The original rules come back on the next load.
- Back up your save before changing your mod list, as always.

## ⚠️ Known Issues
- **The Swift Witchcraft feat's description** (in the feat picker and on its passive) still shows the original text. The new action and its effect have the correct text.
- **With Vanilla Short Rests on**, the "Use Hit Point Dice" action stays in Common Actions, greyed out.
- **The patch's new text is English only.** Other languages show blank or placeholder text for the new toggles and the Swift Witchcraft action.
- **Not compatible with *Val's Variant: DnD 5.5e All-In-One Beyond*** (the full fork). Use the original mod plus this patch instead.
